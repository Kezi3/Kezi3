# Hi, I'm Kezie

Founder of [Ivano Technologies](https://www.ivanotechnologies.com), based in Abuja, Nigeria.

I design and run a team of AI agents that ships production software. Each agent owns one lane: code and deploys, tickets and triage, design QA, comms, and release smoke tests. I direct the work, and I keep a human approval gate on every production release. The agents write most of the code under my direction. I set the architecture, review the changes, and decide what goes live.

**What I lead**

**Stack**
